# Bundled fonts

All fonts in this directory are licensed under the SIL Open Font License 1.1
(see `OFL-amiri.txt`; the same licence text applies to every family below).
They are self-hosted so certificate rendering is deterministic and works
offline; nothing is loaded from Google Fonts at runtime.

| Family | Files | Source |
|---|---|---|
| Amiri | `amiri/Amiri-Regular.ttf`, `amiri/Amiri-Bold.ttf` | https://github.com/google/fonts/tree/main/ofl/amiri |
| Cairo (variable, wght 200–1000) | `cairo/Cairo-Variable.ttf` | https://github.com/google/fonts/tree/main/ofl/cairo |
| Tajawal | `tajawal/Tajawal-Regular.ttf`, `tajawal/Tajawal-Bold.ttf`, `tajawal/Tajawal-ExtraBold.ttf` | https://github.com/google/fonts/tree/main/ofl/tajawal |
| Noto Naskh Arabic (variable, wght 400–700) | `noto-naskh-arabic/NotoNaskhArabic-Variable.ttf` | https://github.com/google/fonts/tree/main/ofl/notonaskharabic |
